# Wander Trips

Portal de viaje para clientes de Wander Trips.

## Primer viaje
Las Vegas · 26–30 octubre 2026 · 4 viajeros

La primera versión incluye vuelos, hospedaje, itinerario día por día, experiencias y pendientes. El diseño es responsive y está pensado principalmente para móvil.
